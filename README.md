# [PeerChat](https://peerchat.lixquid.com)

Peer to peer chat with WebRTC and PeerJS. No accounts, no servers storing your messages.

- **Peer-to-peer** - connects directly between browsers
- **Text & files** - send messages and share files
- **Extra encryption** - optionally add end-to-end encryption on top of the existing secure connection

## Development

```sh
npm run dev      # start a dev server
npm run build    # build for production
npm run preview  # preview the production build
```
